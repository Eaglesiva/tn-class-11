## 3. முக்கியக் கண்டுபிடிப்புகள் (Key Discoveries for Class 11)

1. **2025 Revised Edition (GitHub-ல் உள்ள அதிநவீன பதிப்புகள்)**:
   - `tamil` மற்றும் `maths` (TM Vol-1, Vol-2 மற்றும் EM Vol-1) ஆகிய பாடங்களில் GitHub `main`-ல் இருப்பது **2025 திருத்திய பதிப்பாகும்**.
   - அரசு இணையதளத்தில் 2023/2024 பதிப்பே உள்ளது. எனவே இவற்றை பழைய அரசு PDF-ஆல் மாற்றக்கூடாது (`KEEP_EXISTING`).
2. **பழைய 2018 பதிப்பில் உள்ள பாடங்கள்**:
   - `physics` மற்றும் `chemistry` ஆகியவற்றில் பக்க எண்ணிக்கை 100% அரசு PDF-உடன் பொருந்தினாலும், GitHub-ல் 2018 முதல் பதிப்பு மட்டுமே உள்ளது. அரசு தளத்தில் 2023 Revised / 2024 Reprint உள்ளது.
   - `botany`, `zoology`, `computer_science`, `accountancy` போன்ற பாடங்களில் GitHub-ல் 2018-ன் இரு தொகுதிகள் (Vol-1 + Vol-2) ஒன்றாக இணைக்கப்பட்டு 500-600 பக்கங்களாக உள்ளன. ஆனால் தற்போது அரசு இணையதளத்தில் இவை ஒற்றைப் புத்தகங்களாக (Single Master Volume - 300-380 பக்கங்கள்) வெளியிடப்பட்டுள்ளன.
